# 📖 About

CarBid is a mobile application UI/UX design project developed using Figma as part of the user interface design learning process. The application is designed to help users browse available vehicles, view car details, and explore a simple and user-friendly marketplace interface.

This project focuses on applying UI/UX design principles, including layout organization, color selection, typography, navigation, and user experience, to produce a clean and functional mobile application prototype.
